# Joel Kiggwe | Backend & Systems Engineer Portfolio

Modern, developer-centric portfolio showcasing backend architecture, concurrent-safe APIs, data modeling, and enterprise ERP integrations.

**Live Demo:** [kenjxjj.github.io/j-portfolio](https://kenjxjj.github.io/j-portfolio/)

---

## ⚡ Highlights

- **Developer-First Design:** Minimalist dark-mode interface built with Tailwind CSS.
- **Interactive Live API Console:** Test live backend endpoints (`GET /api/events`, `POST /api/events/:id/book`) directly from the browser with simulated response benchmarking.
- **System Architecture Deep Dives:** Concrete breakdown of race-condition prevention, atomic MongoDB increments (`$inc` + `$expr`), and Odoo ERP batching.
- **Comprehensive Case Studies:** Direct links to production code repositories, schema definitions, and technical specs.

---

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Tailwind CSS, FontAwesome
- **Backend Integrations Highlighted:** Node.js, Express.js, MongoDB Atlas, PostgreSQL, Python 3, Odoo 19
- **Hosting:** GitHub Pages
